## Engenharia de Software Seguro

A Engenharia de Software Seguro busca incorporar segurança durante todo o ciclo de vida do desenvolvimento de software, desde a identificação de ameaças e definição dos requisitos até a implementação, testes, implantação e manutenção.

O trabalho aborda diferentes etapas desse processo, considerando a identificação de vulnerabilidades, a definição de requisitos de segurança, a construção de arquiteturas mais resistentes a ataques e a adoção de práticas de desenvolvimento seguro.


## Escopo

O trabalho está organizado a partir dos seguintes eixos:

### 1. Requisitos de Segurança

Identificação de ameaças e derivação de requisitos não funcionais de segurança a partir dos riscos identificados.

### 2. Vulnerabilidades

Mapeamento e análise de vulnerabilidades catalogadas, considerando suas características, impactos e possíveis estratégias de mitigação.

### 3. Arquitetura Segura

Definição de uma arquitetura que considere princípios de segurança desde as etapas iniciais do desenvolvimento do sistema.

### 4. Código Seguro

Aplicação de boas práticas de programação segura, buscando reduzir a ocorrência de vulnerabilidades durante a implementação.

### 5. Verificação de Vulnerabilidades

Utilização de técnicas e ferramentas para verificar se o software apresenta vulnerabilidades conhecidas ou falhas de segurança.

### 6. Detecção de Intrusões

Estudo dos conceitos relacionados à detecção de intrusões e aos mecanismos utilizados para identificar comportamentos ou atividades suspeitas em sistemas computacionais.

### 7. DevSecOps

Análise do conceito de **DevSecOps**, integrando segurança às práticas de desenvolvimento e operações, de modo que a segurança seja tratada como parte contínua do ciclo de desenvolvimento.
